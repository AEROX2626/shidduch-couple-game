# חוברת בירור מידות לשידוכים — משחק דייטים ושאלון אינטראקטיבי 🕊️

דף נחיתה, שאלון עומק ומשחק דייטים זוגי אינטראקטיבי להכרת האדם ולבניית בית נאמן בישראל, מבוסס על 120 שאלות העומק בבירור מידות.

## ✨ תכונות עיקריות

- 🎮 **משחק הדייט הזוגי ("לבבות ומידות"):**
  - התאמת שמות אישיים לבני הזוג ("הוא & היא" או שמות פרטיים).
  - מנגנון תורים דינמי שמחליף צדדים והופך את השאלות אוטומטית ללשון זכר / נקבה.
  - 3 רמות משחק:
    - 🟢 רמה 1: חימום ושבירת קרח
    - 🟡 רמה 2: ערכים ומידות בפועל
    - 🔴 רמה 3: לב אל לב — בית, חזון וזוגיות
  - 🎁 קלפי הפתעה ומשימות זוגיות (פירגון כנה, שאלת מראה, הקשבה עמוקה, חזון השבת).
  - 🌟 מערכת תגובות וניקוד חיבור (תשובה מעוררת השראה, כנות מרגשת, נקודה למחשבה).
  - 🪙 הטלת מטבע וירטואלית מונפשת להגרלת התור הראשון.
  - 🔊 מנוע צלילים עשיר (Web Audio API) ללא תלות בקבצים חיצוניים.
  - 🎊 חגיגת סיום סבב עם קונפטי וסיכום רגעי החיבור.

- 🃏 **מצב כרטיסיות (Date Focus):** קריאה נקייה וממוקדת של השאלות לשעת הפגישה עם רמזים חבויים למראיין.
- 📋 **מאגר 120 השאלות המלא:** חלוקה ל-12 פרקים, חיפוש חופשי וסינונים מתקדמים.
- ⭐ **20 שאלות הזהב:** שאלות עקרוניות בעדיפות ראשונה לפגישות ראשונות.
- 🗺️ **מפת מידות אישית (פרק ט״ו):** 25 מידות עם מדרגות דירוג (גבוהה/בינונית/דורשת בירור) ושמירת הערות.
- 👥 **בירור חיצוני (פרק י״ג):** 40 שאלות ממוקדות לרבנים, חברים ומכרים עם כפתור העתקה מהירה.
- 🔍 **4 שאלות העומק (פרק י״ד):** כלי מפתח למניעת שיח שטחי.
- 🔤 **פונטים עבים מותאמים לעברית:** רוביק עבה (Rubik ExtraBold), היבו שחור (Heebo Black), סקולר בולד (Secular One).
- 🔒 **פרטיות מלאה:** כל הנתונים נשמרים מקומית בדפדפן (localStorage).

## 🚀 פריסה והרצה

האפליקציה פועלת באופן סטטי ועצמאי לחלוטין.
ניתן להריץ מקומית:
```bash
node server.js
```
האתר ייפתח בכתובת: `http://localhost:3005`
